## 1. 需求分析

### 1.1 背景

现代家庭冰箱管理存在三个痛点：（1）食材买回来塞进冰箱后就忘了，过期浪费严重；（2）面对一冰箱食材不知道能做什么菜；（3）缺乏对家庭饮食营养的全局认知。本项目设计一款 Android APP，通过模拟视觉识别录入食材，结合营养学知识匹配菜谱并生成购物清单，帮助用户减少食物浪费、科学饮食。

### 1.2 用户故事

- 用户打开冰箱 → 手机拍照 → APP 识别食材 → 自动入库
- 食材即将过期 → 通知提醒 → 推荐含该食材的菜谱
- 用户说"今晚做什么吃？"→ APP 根据现有食材推荐菜谱
- 用户做了一道菜 → 记录摄入 → 营养报告自动更新
- 缺食材 → 一键生成购物清单

### 1.3 技术约束

- 平台：Android（最低 API 26）
- 本地存储：SQLite
- 云端：华为云 IoT 平台（模拟食材数据同步）
- 视觉识别：客户端模拟（拍照 → 识别动画 → 返回预设结果）

## 3. 功能设计

### 3.1 冰箱总览（MainActivity）

- 食材 GridView 展示，按类别分组（蔬菜/水果/肉类/乳制品/其他）
- 三色过期标记：🟢 新鲜（>3天）、🟡 即将过期（1-3天）、🔴 已过期
- 搜索框实时过滤
- 点击食材查看详情/删除/标记用完
- 从其他 Activity 返回时自动刷新

### 3.2 食材录入（ScanActivity）

- 拍照按钮 → 调用相机 → 拍摄后显示"AI 识别中..."3 秒动画
- 模拟识别结果：从预设库随机匹配食材（演示时模拟，正式可对接真实视觉 API）
- 手动修正食材名称、类别、数量、保质期
- 确认后写入 SQLite 并返回总览页

### 3.3 智能菜谱（RecipeActivity）

- 根据当前冰箱食材自动匹配菜谱
- 匹配算法：菜谱所需食材 ∩ 现有食材 ≥ 80% → 可做
- 菜谱列表显示匹配度百分比 + 缺失食材
- 菜谱详情页：步骤、营养信息、缺失食材一键加入购物清单
- 搜索/浏览完整菜谱库（包含部分不匹配的，鼓励扩展食材）

### 3.4 营养报告（NutritionActivity）

- 本周摄入概览卡片（热量/蛋白质/脂肪/碳水化合物）
- 雷达图对比推荐摄入量
- 折线图展示 7 天热量变化趋势
- 智能建议（"本周蛋白质摄入偏低，推荐增加豆制品"）
- 购物清单管理：添加/勾选完成/清除

### 3.5 后台服务

- 每日 8:00 检查到期食材 → 通知栏提醒
- 每周日晚生成营养周报 → 通知用户查看

### 4.3 关键查询示例

**查询即将过期的食材（48 小时内）：**
```sql
SELECT name, buy_date, expire_days,
       date(buy_date, '+' || expire_days || ' days') AS expire_date
FROM ingredient
WHERE date(buy_date, '+' || expire_days || ' days') <= date('now', '+2 days');
```

**查询可用菜谱（匹配度 ≥ 80%）：**
```sql
SELECT r.*, 
       COUNT(ri.id) AS total_needed,
       SUM(CASE WHEN i.id IS NOT NULL THEN 1 ELSE 0 END) AS available,
       CAST(SUM(CASE WHEN i.id IS NOT NULL THEN 1 ELSE 0 END) AS REAL) / COUNT(ri.id) AS match_rate
FROM recipe r
JOIN recipe_ingredient ri ON r.id = ri.recipe_id
LEFT JOIN ingredient i ON ri.ingredient_name = i.name
GROUP BY r.id
HAVING match_rate >= 0.8
ORDER BY match_rate DESC;
```

**本周营养摄入统计：**
```sql
SELECT SUM(r.calories) AS total_cal,
       SUM(r.protein) AS total_protein,
       SUM(r.fat) AS total_fat,
       SUM(r.carbs) AS total_carbs
FROM intake_log il
JOIN recipe r ON il.recipe_id = r.id
WHERE il.date >= date('now', 'weekday 1', '-7 days');
```

### 6.2 菜谱匹配算法

```java
public List<Recipe> matchRecipes(List<Ingredient> fridgeItems) {
    List<Recipe> allRecipes = recipeDao.getAll();
    List<Recipe> matched = new ArrayList<>();
    
    for (Recipe r : allRecipes) {
        List<String> needed = recipeDao.getIngredients(r.id);
        int available = 0;
        List<String> missing = new ArrayList<>();
        
        for (String ing : needed) {
            if (fridgeItems.stream().anyMatch(i -> i.name.equals(ing))) {
                available++;
            } else {
                missing.add(ing);
            }
        }
        
        double rate = (double) available / needed.size();
        if (rate >= 0.8) {
            r.matchRate = rate;
            r.missingIngredients = missing;
            matched.add(r);
        }
    }
    
    Collections.sort(matched, (a, b) -> Double.compare(b.matchRate, a.matchRate));
    return matched;
}
```

## 8. 工作小结

本项目以"家庭冰箱管理"为切入点，设计了基于 Android 的智能冰箱管家 APP。核心创新点在于将**模拟视觉识别录入、营养学分析、菜谱智能匹配**三个环节串联，形成"录入 → 管理 → 推荐 → 分析 → 采购"的完整闭环。

技术实现上使用了 SQLite（Room）做本地存储，Service + AlarmManager 做定时任务，MPAndroidChart 做数据可视化，华为云 IoT 做数据同步。数据库设计涵盖了 5 张关联表，包含多表联合查询、聚合统计、条件过滤等复杂 SQL 操作。

项目在演示时可完整展示拍照录入食材、食材过期预警、菜谱匹配推荐、营养报告生成等核心流程，满足课程考核的全部评分要求。
