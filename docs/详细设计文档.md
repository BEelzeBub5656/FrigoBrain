## 1. 需求分析

### 1.1 背景

现代家庭冰箱管理存在三个痛点：（1）食材买回来塞进冰箱后就忘了，过期浪费严重；（2）面对一冰箱食材不知道能做什么菜；（3）缺乏对家庭饮食营养的全局认知。本项目设计一款 Android APP，通过模拟视觉识别录入食材，结合营养学知识匹配菜谱并生成购物清单，并通过华为云 IoT 平台同步数据，减少食物浪费、促进科学饮食。

### 1.2 核心功能

- 拍照模拟 AI 识别录入食材，自动计算保质期
- 食材三色过期预警（红/黄/绿）
- 根据现有食材智能匹配菜谱（覆盖率达 80% 以上）
- 营养雷达图 + 周趋势分析
- 一键生成购物清单
- 华为云 IoT 平台实时同步库存数据
- 每日 8:00 食材过期通知提醒

### 2.2 技术选型

## 3. 功能设计

### 3.1 Activity 清单（6 个）

| # | Activity | 功能 | 入口 |
|---|----------|------|------|
| 1 | LoginActivity | 启动页，用户登录 | LAUNCHER |
| 2 | MainActivity | 仪表盘：食材统计 + 过期预警 + 快捷入口 + IoT 状态栏 | 登录后 |
| 3 | InventoryActivity | 食材库存管理 GridView，分类筛选，红黄绿标记 | 底部导航 |
| 4 | FoodAddActivity | 食材录入（拍照→"AI 识别"→入库） | 快捷按钮 |
| 5 | RecipeListActivity | 菜谱推荐 + 搜索 + 匹配度排序 | 底部导航 |
| 6 | NutritionActivity | 营养摄入统计 + 周热量汇总 | 底部导航 |

### 3.2 仪表盘（MainActivity）

- 食材总览：总种类 / 即将过期数
- 过期横幅：3 天内过期食材列表（点击跳转库存）
- 快捷入口：加食材 / 看菜谱 / 营养统计
- IoT 状态栏：点击手动同步 → 显示 "☁️ 华为云：已连接 ✅"
- 动态版本号显示
- 双击返回键退出

### 3.3 食材录入（FoodAddActivity）

- 拍照按钮 → 调用 CameraX 拍照
- 显示 "AI 识别中..." 动画（模拟视觉识别）
- 手动确认食材名、类别、数量、保质期
- 入库后自动刷新库存

### 3.4 智能菜谱（RecipeListActivity）

- 菜谱匹配算法：菜谱所需食材 ∩ 现有食材 ≥ 80% → 可做
- 匹配度百分比排序
- 菜谱详情（热量/蛋白质/脂肪/碳水/步骤）
- 缺食材一键加入购物清单

### 3.5 营养报告（NutritionActivity）

- 本周热量摄入统计
- 食材列表实时展示（红黄绿过期标记 + 剩余天数）
- 基于中国居民膳食指南的推荐值对比

### 3.6 后台服务

| Service | 功能 | 触发 |
|---------|------|------|
| ExpiryCheckService | 每日 8:00 检查过期食材 → 通知栏提醒 | AlarmManager |
| IotDataSyncService | 每 30 分钟同步库存到华为云 IoTDA | AlarmManager + 开机自启 |

## 5. IoT 通信设计

### 5.1 华为云 IoTDA 连接

| 参数 | 值 |
|------|-----|
| 端点 | `ssl://21158429fd.st1.iotda-device.cn-north-4.myhuaweicloud.com:8883` |
| 协议 | MQTT over SSL (Paho 原生 ssl://) |
| 认证 | HMAC-SHA256，密码 = hex(hmac(device_secret, UTC timestamp)) |
| 设备 ID | FrigoBrain5656_FrigoBrain5656_BEEL |
| 同步频率 | 每 30 分钟 |

### 5.2 通信流程

```
App 启动 → 3s 后启动 IotDataSyncService
         → MqttClient.connect()
         → HMAC 计算密码
         → MQTTS 握手
         → 连接成功 → sendBroadcast("CONNECTED")
         → reportProperties("inventorySync", {...})
         → 每 30 分钟定时同步
```

## 8. 工作小结

本项目实现了基于 Android + 华为云 IoT 的智能冰箱管家 APP，包含 6 个 Activity、11 个 Room 实体、9 个 DAO 接口。核心技术亮点包括：

1. **华为云 IoTDA 真实连接**：使用 Eclipse Paho 客户端通过 MQTTS 协议连接华为云，实现 HMAC-SHA256 认证、库存数据上行，UI 实时显示连接状态。
2. **Room 数据库**：11 表联动，支持复杂联合查询（到期食材、菜谱匹配度、周营养统计）。
3. **种子数据**：首次安装即有 18 种食材 + 20 道菜谱 + 7 天完整营养日志，演示即开即用。
4. **后台服务**：ExpiryCheckService 定时过期通知 + IotDataSyncService 定时云同步。
5. **模拟视觉识别**：CameraX 拍照 → 识别动画 → 手动修正，交互流程完整。

项目代码位于 [GitHub](https://github.com/BEelzeBub5656/FrigoBrain)，包含完整 Android 源码、审阅记录和 CI 构建配置。
