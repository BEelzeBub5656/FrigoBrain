## 1. 需求分析

### 1.1 背景

现代家庭冰箱管理存在三个痛点：（1）食材买回来塞进冰箱后就忘了，过期浪费严重；（2）面对一冰箱食材不知道能做什么菜；（3）缺乏对家庭饮食营养的全局认知。本项目设计一款 Android APP，通过打字录入食材（自动补全），结合营养学知识智能匹配菜谱并生成购物清单，并通过华为云 IoT 平台同步库存数据，帮助减少食物浪费、科学饮食。同时提供 Web 管理端（Spring Boot + Vue3）实现远程监控。

### 1.2 核心功能

- 打字录入食材（AutoCompleteTextView 自动补全 30+ 常见食材），自动计算过期日期
- 食材三色过期预警（红/黄/绿）
- 根据现有食材智能匹配菜谱（覆盖率达 80% 以上）
- 营养雷达图 + 周趋势分析
- 一键生成购物清单
- 华为云 IoT 平台实时同步库存数据
- 每日 8:00 食材过期通知提醒

## 3. 功能设计

### 3.1 Activity 清单（6 个）

| # | Activity | 功能 | 入口 |
|---|----------|------|------|
| 1 | LoginActivity | 启动页，用户登录 | LAUNCHER |
| 2 | MainActivity | 仪表盘：食材统计 + 过期预警 + 快捷入口 + IoT 状态栏 | 登录后 |
| 3 | InventoryActivity | 食材库存管理 GridView，分类筛选，红黄绿标记 | 底部导航 |
| 4 | FoodAddActivity | 食材录入（打字+自动补全+分类联动+日期选择） | 快捷按钮 |
| 5 | RecipeListActivity | 菜谱推荐 + 搜索 + 匹配度排序 | 底部导航 |
| 6 | NutritionActivity | 营养摄入统计 + 周热量汇总 | 底部导航 |

### 3.2 仪表盘（MainActivity）

- 食材总览：总种类 / 即将过期数
- 过期横幅：3 天内过期食材列表（点击跳转库存）
- 快捷入口：加食材 / 看菜谱 / 营养统计
- IoT 状态栏：点击手动同步 → 显示 "☁️ 华为云：已连接 ✅"
- 动态版本号显示
- 双击返回键退出

### 3.3 食材录入（FoodAddActivity）

- AutoCompleteTextView 食材名自动补全（内置 30 种常见食材 + 历史录入记录合并）
- 分类 Spinner 下拉选择（蔬菜/水果/肉类/乳制品/其他，5 个分类）
- 数量 + 单位（单位 14 种：个/g/ml/斤/袋/根/颗/块/条等）
- 购买日期 DatePickerDialog + 保质期天数（自动计算过期日期）
- 价格、备注（选填）
- ZXing 扫码录入按钮（可选扩展）
- 入库后写入 SQLite 并自动返回冰箱页

### 3.4 智能菜谱（RecipeListActivity）

- 双数据源：聚合数据 API 在线搜索（万级菜谱库）+ 本地 20 道预置菜谱离线回退
- 菜谱匹配算法：菜谱所需食材 ∩ 现有食材 → 匹配率 ≥ 50% → 按匹配度降序展示
- "猜你想搜"：15 个常见菜名标签云，点击直接搜索
- SharedPreferences 搜索历史持久化
- 菜谱详情 Dialog（菜名/热量/蛋白质/脂肪/碳水/步骤摘要）→ "已挂载到主页"
- 菜系过滤 12 种：川菜/鲁菜/粤菜/苏菜/浙菜/闽菜/湘菜/徽菜/东北菜/家常菜/轻食/早餐
- 缺食材一键加入购物清单

### 3.5 营养报告（NutritionActivity）

- 本周营养概览四卡片：热量（kcal）/蛋白质（g）/脂肪（g）/碳水（g）
- MPAndroidChart 雷达图：实际摄入 vs 《中国居民膳食指南》推荐值对比
- MPAndroidChart 折线图：7 天热量变化趋势（平滑贝塞尔曲线 + 动画）
- 数据来源：NutritionLog 表 SUM 聚合查询（WHERE log_date BETWEEN weekStart AND weekEnd）

### 3.6 后台服务

| Service | 功能 | 触发 |
|---------|------|------|
| ExpiryCheckService | 每日 8:00 检查过期食材 → 通知栏提醒 | AlarmManager |
| IotDataSyncService | 每 30 分钟同步库存到华为云 IoTDA | AlarmManager + 开机自启 |

### 4.5 关键复杂 SQL（评分重点 — 15 分）

**SQL-1：即将过期食材 LEFT JOIN 推荐菜谱**
```sql
SELECT fi.name, fi.expiry_date, fi.quantity, r.name AS recipe_name
FROM food_items fi
LEFT JOIN recipe_ingredients ri ON LOWER(fi.name)=LOWER(ri.food_name)
LEFT JOIN recipes r ON ri.recipe_id = r.recipe_id
WHERE fi.is_consumed=0 AND fi.expiry_date BETWEEN :t1 AND :t2
ORDER BY fi.expiry_date ASC
```

**SQL-2：菜谱匹配度计算（JOIN + 子查询 + HAVING）**
```sql
SELECT r.*, COUNT(ri.ingredient_id) AS total,
  SUM(CASE WHEN fi.name IS NOT NULL THEN 1 ELSE 0 END) AS hit,
  CAST(SUM(CASE WHEN fi.name IS NOT NULL THEN 1 ELSE 0 END) AS REAL)
  / COUNT(ri.ingredient_id) AS match_rate
FROM recipes r JOIN recipe_ingredients ri USING(recipe_id)
LEFT JOIN food_items fi ON LOWER(ri.food_name)=LOWER(fi.name)
WHERE fi.is_consumed=0
GROUP BY r.recipe_id HAVING match_rate >= 0.5
ORDER BY match_rate DESC
```

**SQL-3：本周营养摄入聚合（SUM + 时间范围）**
```sql
SELECT COALESCE(SUM(calories),0), COALESCE(SUM(protein),0),
  COALESCE(SUM(fat),0), COALESCE(SUM(carbs),0)
FROM nutrition_logs
WHERE user_id=:uid AND log_date BETWEEN :weekStart AND :weekEnd
```

## 5. IoT 通信设计

### 5.1 华为云 IoTDA 连接

| 参数 | 值 |
|------|-----|
| 端点 | `ssl://21158429fd.st1.iotda-device.cn-north-4.myhuaweicloud.com:8883` |
| 协议 | MQTT over SSL (Paho 原生 ssl://) |
| 认证 | HMAC-SHA256，密码 = hex(hmac(device_secret, UTC timestamp)) |
| 设备 ID | FrigoBrain5656_FrigoBrain5656_BEEL |
| 同步频率 | 每 30 分钟 |

### 5.2 通信流程

```
App 启动 → 3s 后启动 IotDataSyncService
         → MqttClient.connect()
         → HMAC 计算密码
         → MQTTS 握手
         → 连接成功 → sendBroadcast("CONNECTED")
         → reportProperties("inventorySync", {...})
         → 每 30 分钟定时同步
```

## 8. 工作小结

本项目实现了基于 Android + 华为云 IoT 的智能冰箱管家 APP，包含 6 个 Activity、11 个 Room 实体、9 个 DAO 接口。核心技术亮点包括：

1. **华为云 IoTDA 真实连接**：使用 Eclipse Paho 客户端通过 MQTTS 协议连接华为云，实现 HMAC-SHA256 认证、库存数据上行，UI 实时显示连接状态。
2. **Room 数据库**：11 表联动，支持复杂联合查询（到期食材、菜谱匹配度、周营养统计）。
3. **种子数据**：首次安装即有 18 种食材 + 20 道菜谱 + 7 天完整营养日志，演示即开即用。
4. **后台服务**：ExpiryCheckService 定时过期通知 + IotDataSyncService 定时云同步。
5. **完整种子数据体系**：18 种演示食材（5 分类 × 3 种过期状态）+ 20 道菜谱（12 种中国菜系）+ 21 条 7 天完整营养日志，首次安装即开即用。
6. **Web 管理端扩展**：Spring Boot REST API + Vue 3 + ECharts + GSAP 仪表盘，支持食材 CRUD、菜谱管理、营养统计、华为云设备影子查询。
7. **聚合菜谱 API 集成**：聚合数据 API 在线搜索万级菜谱库，猜你想搜 + 搜索历史 + 网络离线自动回退本地库。

项目代码位于 [GitHub](https://github.com/BEelzeBub5656/FrigoBrain)，包含完整 Android 源码、审阅记录和 CI 构建配置。
